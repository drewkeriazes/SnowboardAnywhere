# History rewrite, 2026-11-06 (DATA-017)

On 2026-11-06 `main` was rewritten to remove 570 pack tiles (158 MB) that commit `8fa9b3e` ("add topo data") added by mistake from a mis-named `packsvail/` output folder. - Every commit from `8fa9b3e` onward got a new hash. The 8 commits before it kept theirs. Authors, dates and messages are unchanged.
- Signed cloud-session commits in the rewritten range lost their SSH signature (GitHub's "Verified" badge).
- Hashes quoted in `docs/` were updated to the new ones. Hashes in issue comments, commit messages and the closed PR #1 still use the old ones: translate them with the table below.
- A full backup of the old history is on Drew's PC: `C:\Users\Drew\Documents\snowboard-sim\backup\SnowboardAnywhere-before-purge-2026-11-06.bundle` (restore with `git clone <bundle>`).
- Any other clone made before the rewrite must be re-cloned, or reset with `git fetch` then `git reset --soft origin/main` (the final trees are identical). Do not merge or rebase old history onto the new `main`.
